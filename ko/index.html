POLY_PHONY 참여 방법 · How POLY_PHONY works

POLY_PHONY의 작품은 제작 과정을 공개하고, 관객의 의견으로 개정한다. 남긴 기록은 그대로 크레딧이 된다.

  1. 01읽는다작품과 제작 과정을 본다
  2. 02의견을 남긴다레퍼런스·연출·디자인 피드백 / 또는 방명록에 다녀감만
  3. 03크레딧에 기록된다채택되면 기여 보상 포인트 + 크레딧 · 채택되지 않아도 기본 포인트와 크레딧에 남는다
  4. 04원하면 크루로피드백 폼의 체크 하나로 제작 참여를 신청한다

피드백 마감은 작품 설계자의 판단과 함께 예고 없이 찾아갑니다. POLY_PHONY 프로젝트는 수익과 크레딧뿐 아니라 마감의 압박 역시 쉐어합니다.

참여자 전원에게 요청 시 스튜디오 참여·크레딧 확인서를 발급한다 (포트폴리오용 자체 증명서 — 공공기관의 예술활동증명을 대체하지 않는다).

작품은 4가지 채널로 기록된다
  1. 01홈페이지버전·의견·크레딧 공개 아카이브
  2. 02이북스토리 판본과 창작 사유
  3. 03영상본편·크레딧
  4. 04상영·전시완성작 공개
